📍 greatestBitPos() - 返回最高有效1位的掩码

int greatestBitPos(int x) { /* 将所有1位向右传播,然后取异或得到最高位 */ int temp = x; temp = temp | (temp >> 1); temp = temp | (temp >> 2); temp = temp | (temp >> 4); temp = temp | (temp >> 8); temp = temp | (temp >> 16); return temp ^ ((temp >> 1) & ~(1 << 31)); }

💡 原理说明:
使用右传播技术：将最高位1向右传播，使所有低位都变成1。
公式: temp ^ ((temp >> 1) & ~(1 << 31))
其中 temp 是通过多次 x | (x >> n) 传播得到的全1模式。

➖ isNegative() - 判断是否为负数

公式: (x >> 31) & 1
算术右移31位后，最低位即为原数的符号位。

⚖️ isGreater() - 判断 x > y

int isGreater(int x, int y) { int sign_x = (x >> 31) & 1; int sign_y = (y >> 31) & 1; int diff = y + (~x + 1); /* y - x */ int sign_diff = (diff >> 31) & 1; int same_sign = !(sign_x ^ sign_y); int not_equal = !!diff; return ((same_sign & sign_diff & not_equal) | (!same_sign & !sign_x)) & 1; }
结果:
-
💡 原理说明:
需要考虑溢出情况。分三种情况：
1. x正y负：直接返回1
2. x负y正：直接返回0
3. 同号：计算 y - x，如果结果为负且不相等，则 x > y
公式涉及符号位比较和差值的符号判断。
