# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## 项目概述

这是 CS:APP（深入理解计算机系统）Data Lab - 位操作谜题实验。学生需要在 `bits.c` 中使用受限的操作符实现 14 个谜题函数来解决位操作问题。

## 编译和测试命令

### 使用 dlc 检查代码合规性
```bash
cd lab1
python3 dlc.py bits.c
```
dlc 会检查每个函数是否:
- 只使用了注释中允许的操作符
- 操作数未超过最大限制
- 没有使用禁止的控制语句 (if, while, for 等)
- 没有使用大于 0xFF 的常量

### 编译并运行测试
```bash
cd lab1
gcc -o btest bits.c btest.c decl.c getopt.c tests.c
./btest
```

### 测试单个函数
```bash
./btest -f <函数名>
```
示例: `./btest -f bitAnd`

### 查看评分摘要
```bash
./btest -g
```

### 详细输出模式
```bash
./btest -v 1    # 显示每个函数的测试结果和得分
./btest -v 0    # 只显示简洁的评分摘要
```

### 限制错误输出数量
```bash
./btest -e <N>  # 限制每个函数报告的错误数为 N
```

## 代码架构

### 源文件说明
- **[bits.c](lab1/bits.c)** - 学生解答文件。包含 `team_struct` 学生信息和 14 个待实现的谜题函数。
- **[tests.c](lab1/tests.c)** - 参考实现（test_* 函数），用于验证学生解答的正确性。
- **[decl.c](lab1/decl.c)** - 测试注册表（`test_set[]` 数组），定义每个谜题的约束：函数名、参数个数、合法操作符、最大操作数、分值和参数范围。
- **[btest.c](lab1/btest.c)** - 测试框架，生成测试值并比较学生函数与参考实现的结果。
- **[btest.h](lab1/btest.h)** - 类型定义，包括 `team_struct`、函数指针和 `test_rec` 结构体。

### 谜题约束规则

每个谜题函数在其头部注释和 `decl.c` 中都有严格的规定：

1. **合法操作符**: 每个函数只能使用 `! ~ & ^ | + << >>` 的子集
2. **最大操作数**: 允许使用的操作符最大数量（如 bitAnd 允许 8 个操作）
3. **分值**: 难度评分（1-4 分）

### 禁止使用的结构
- 控制语句: `if`、`do`、`while`、`for`、`switch`
- 宏定义
- 函数调用（在谜题函数内部）
- 强制类型转换
- 禁用操作符: `&&`、`||`、`-`、`?:`
- 大于 0xFF (255) 的常量，特殊情况如 `0xffffffff` 除外

### 允许使用
- 0-255 (0xFF) 的整数常量
- 函数参数和局部变量
- 操作符: `! ~ & ^ | + << >>`
- 赋值 (`=`) 不计入操作数限制，可以无限使用

| reverseBytes | 1 | 全部 | 25 | 3 | 反转 x 的字节顺序 |

## 注意事项

- 使用 32 位补码整数表示
- 右移为算术右移（符号位扩展）
- 测试值在边界情况和参数范围内随机生成
