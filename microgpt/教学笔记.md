# 第一部分：MicroGPT 总览

## 0. 目标是什么？

**给一个名字的一部分，猜下一个字母。**

比如看到了 `emm`，猜下一个字母可能是 `a`（emma）。这就是整个 microgpt 做的事 — 一个"猜下一个字符"的程序。

## 1. 把文字变成数字

计算机不认识字母，只认识数字。所以第一步是建立一张映射表：

```python
# 数据集里出现的所有唯一字符，排个序
uchars = sorted(set(''.join(docs)))

# 比如：'a' → 0, 'b' → 1, 'c' → 2, ..., 'z' → 25
```

然后加一个特殊标记 `BOS`（Beginning of Sequence），编号 26，表示"句子开始了"。

```python
BOS = len(uchars)  # 26
```

这样一个名字 `emma` 就变成数字序列：

```
[BOS, 'e', 'm', 'm', 'a', BOS]
↓
[26,   4,  12, 12, 0,  26]
```

最后为什么还有个 BOS？因为模型需要知道什么时候**停止**。生成时如果又吐出了 BOS，就说明"这个名字结束了"。

## 2. 模型到底是什么？

模型就是一个**巨大的函数**。输入数字，输出数字。

具体来说：输入"当前 token 的编号"和"位置编号"，输出一个长度为 `vocab_size` 的分数列表（logits），每个分数对应一个字符是"下一个字符"的可能性。

```
输入: token_id=4 (字母'e'), pos_id=0
输出: [0.1, -0.3, 0.5, ..., 2.1, ...]   ← 共 vocab_size 个数
                              ↑
                        分数最高，说明模型认为下一个字母很可能是某个字符
```

但这个"巨大的函数"不是我们手写的，而是由**参数（parameters）** 控制的。参数就是一堆数字，通过学习来调整。

## 3. 最简单的"可学习函数" — 线性层

线性层（Linear Layer）是最基本的积木：

```
输入: x = [x1, x2, ..., xn]    （n 个数）
参数: W = 一个 n_out × n_in 的矩阵
输出: y = W × x                 （n_out 个数）
```

代码里这样写（第 94-95 行）：

```python
def linear(x, w):
    return [sum(wi * xi for wi, xi in zip(wo, x)) for wo in w]
```

展开就是：对矩阵的每一行 `wo`，和输入向量 `x` 做点积，得到一个数。所有行合起来就是输出向量。

**这就是"可学习的函数"** — 改变矩阵 W 里的数字，函数的行为就变了。

## 4. Softmax — 把分数变成概率

logits 是任意实数（可正可负），我们需要把它变成概率（0 到 1 之间，加起来等于 1）。

公式：

```
softmax(logits) = exp(logit_i) / Σ exp(logit_j)
```

代码（第 97-101 行）：

```python
def softmax(logits):
    max_val = max(val.data for val in logits)   # 减最大值，防止数值溢出
    exps = [(val - max_val).exp() for val in logits]
    total = sum(exps)
    return [e / total for e in exps]
```

减去 `max_val` 是数值稳定技巧 — 不改变结果但防止 `exp()` 爆炸。

## 5. 怎么知道模型猜得对不对？— 损失函数

假设模型对下一个字符的预测概率是 `probs[target] = 0.05`，也就是只有 5% 的概率猜对了。

我们希望这个概率越大越好。取负对数作为损失：

```
loss = -log(概率)
```

- 猜对了（概率=1）：loss = -log(1) = 0（完美）
- 猜错了（概率≈0）：loss = -log(0) → ∞（极差）

代码（第 167 行）：

```python
loss_t = -probs[target_id].log()
```

对序列中每个位置都算一个 loss，然后取平均（第 169 行）。

## 6. 怎么让模型变好？— 梯度和反向传播

这是最关键的概念。

**梯度（gradient）** 回答的问题是：**"如果某个参数微微增大一点点，loss 会怎么变？"**

- 梯度为正 → 增大该参数会使 loss 增大 → 我们应该**减小**它
- 梯度为负 → 增大该参数会使 loss 减小 → 我们应该**增大**它

所以更新规则就是：

```
参数 = 参数 - 学习率 × 梯度
```

这就是**梯度下降** — 沿着让 loss 下降的方向调整参数。

### 反向传播（Backpropagation）

但参数有几万个，每个都要算梯度。怎么算？

利用**链式法则（chain rule）**。如果你学过微积分，链式法则是：

```
dy/dx = dy/du × du/dx
```

microgpt 的 `Value` 类就是把这个过程自动化了：

```python
class Value:
    def __init__(self, data, children=(), local_grads=()):
        self.data = data
        self.grad = 0
        self._children = children       # 这个节点是谁算出来的
        self._local_grads = local_grads # 对每个子节点的局部导数
```

每次做运算（比如 `a + b`），就记录：
- 子节点：`(a, b)`
- 局部梯度：`(∂result/∂a, ∂result/∂b)` = `(1, 1)`

乘法 `a * b` 的局部梯度就是 `(b, a)`，因为 `∂(a×b)/∂a = b`。

然后 `backward()` 从 loss 开始，沿着计算图**反向**传播梯度（第 59-72 行）：

```python
def backward(self):
    # 1. 拓扑排序：确定计算顺序（先算依赖少的）
    topo = []
    def build_topo(v):
        if v not in visited:
            for child in v._children:
                build_topo(child)
            topo.append(v)
    build_topo(self)

    # 2. 反向遍历，累加梯度
    self.grad = 1   # loss 对自己的梯度是 1
    for v in reversed(topo):
        for child, local_grad in zip(v._children, v._local_grads):
            child.grad += local_grad * v.grad   # 链式法则！
```

**一句话总结**：前向传播算出 loss，反向传播算出每个参数的梯度，梯度告诉我们该怎么调参。

## 7. Adam 优化器 — 更聪明的调参方式

最简单的更新是 `参数 -= lr × 梯度`，但 Adam 更聪明，它维护两个移动平均：

```python
m[i] = β1 × m[i] + (1-β1) × grad     # 一阶矩：梯度的"平均值"（方向）
v[i] = β2 × v[i] + (1-β2) × grad²    # 二阶矩：梯度平方的"平均值"（大小）
```

然后做偏差校正后更新：

```
参数 -= lr × m_hat / (sqrt(v_hat) + eps)
```

直觉：梯度大但一直振荡的方向 → 二阶矩大 → 步长自动缩小。梯度稳定的方向 → 步长保持。**自适应学习率**。

## 8. Transformer — 模型架构

核心架构（`gpt` 函数，第 108-144 行）：

```
输入: (token_id, pos_id)
        ↓
┌─────────────────────────────┐
│  Token Embedding + Position Embedding  │
│  tok_emb = wte[token_id]             │
│  pos_emb = wpe[pos_id]               │
│  x = tok_emb + pos_emb               │
└─────────────────────────────┘
        ↓
┌─────────────────────────────┐
│  Transformer Block (× n_layer)       │
│                                      │
│  ┌─ Multi-Head Self-Attention ──┐   │
│  │  x_norm = rmsnorm(x)        │   │
│  │  Q = linear(x_norm, Wq)     │   │
│  │  K = linear(x_norm, Wk)     │   │
│  │  V = linear(x_norm, Wv)     │   │
│  │                              │   │
│  │  attention = softmax(QK^T/√d)│   │
│  │  output = attention × V      │   │
│  │  output = linear(output, Wo) │   │
│  │  x = output + x (残差连接)   │   │
│  └──────────────────────────────┘   │
│                                      │
│  ┌─ MLP (前馈网络) ─────────────┐   │
│  │  x_norm = rmsnorm(x)        │   │
│  │  x = linear(x_norm, fc1)    │   │
│  │  x = ReLU(x)                │   │
│  │  x = linear(x, fc2)         │   │
│  │  x = output + x (残差连接)   │   │
│  └──────────────────────────────┘   │
└─────────────────────────────┘
        ↓
    logits = linear(x, lm_head)
```

### 逐块解释：

**Embedding**：把离散的 token id 变成连续向量。`wte[4]` 就是查表，把 id=4 映射成一个 16 维向量。`wpe[0]` 是位置 0 的向量。两者相加，让模型同时知道"是什么字符"和"在哪个位置"。

**RMSNorm**：把向量归一化，防止数值太大或太小。比 LayerNorm 简单 — 不需要减均值，只除以均方根：

```python
def rmsnorm(x):
    ms = sum(xi * xi for xi in x) / len(x)    # 均方
    scale = (ms + 1e-5) ** -0.5                # 缩放因子
    return [xi * scale for xi in x]
```

**Self-Attention（自注意力）** — 这是 Transformer 的灵魂：

核心思想：**每个位置要"看"之前所有位置的信息，决定该关注谁。**

```
Q (Query)  = "我在找什么"
K (Key)    = "我有什么"
V (Value)  = "我的内容"
```

**KV-Cache**：注意第 121-122 行 `keys[li].append(k)` — 每生成一个新 token，把它的 K 和 V 存下来。这样下一个位置就不用重新算之前所有的 K、V。这是自回归生成中的经典优化。

**残差连接**：`x = output + x_residual`（第 134、141 行）。把子层的输出**加回**原始输入上。作用是让梯度能直接流过去，缓解深层网络训练困难。

**MLP**：两层线性变换 + ReLU 激活，给模型非线性拟合能力。维度先扩大 4 倍（`4 × n_embd`），再缩回来。

## 9. 完整的训练流程

```
for step in range(1000):
    ① 取一条数据，变成 token 序列
    ② 逐位置前向传播，计算每个位置的预测概率和 loss
    ③ 反向传播，算所有参数的梯度
    ④ Adam 优化器更新参数
    ⑤ 打印 loss
```

## 10. 推理（生成）

训练好的模型怎么用？

```python
token_id = BOS              # 从起始符开始
for pos_id in range(block_size):
    logits = gpt(token_id, pos_id, keys, values)   # 模型预测
    probs = softmax(logits / temperature)           # temperature 控制随机性
    token_id = random.choices(range(vocab_size), weights=[p.data for p in probs])[0]
    if token_id == BOS: break                       # 遇到终止符就停
```

`temperature` 越小，越倾向于选概率最高的（保守）；越大越随机（有创造力）。

## 各模块速查表

| 模块 | 作用 |
|------|------|
| Tokenizer | 字母 → 数字 |

# 第二部分：Attention Is All You Need 深度详解

## 一、论文在解决什么问题？

论文标题全称是 **"Attention Is All You Need"**，发表于 2017 年，任务是**机器翻译**：

```
输入: "I love you"
输出: "我爱你"
```

在它之前，主流方法是 **Encoder-Decoder + RNN**：

```
Encoder(RNN): 一个字一个字地读入 "I" → "love" → "you"
              最后得到一个"隐藏状态"h（一个向量）
Decoder(RNN): 从 h 出发，一个字一个字地生成 "我" → "爱" → "你"
```

### 问题在哪？

```
"I love you very much and I think that you are the most beautiful person in the world"

整个这句话被 RNN 读完后，压缩成 一个固定长度的向量 h。
```

**信息瓶颈** — 不管句子多长，都被压缩成一个固定大小的向量，信息必然会丢失。

后来的改进叫 **Bahdanau Attention**（2014），让 Decoder 在生成每个词时都能回头看 Encoder 的所有输出，而不是只看最后一个 h。但这套系统**仍然依赖 RNN**，必须从左到右一步步算，无法并行。

Transformer 的核心贡献：**完全扔掉 RNN，只用注意力机制来传递信息。** 这样既解决了信息瓶颈，又能并行计算。

## 二、从文字到向量 — Embedding

### 2.1 什么是 Embedding？

计算机只懂数字，不懂文字。所以每个词需要变成一个**向量**（一列数字）。

假设我们的词汇表只有 6 个词：`["我", "爱", "你", "他", "恨", "猫"]`

最朴素的方法是 One-Hot 编码：

```
"我" → [1, 0, 0, 0, 0, 0]
"爱" → [0, 1, 0, 0, 0, 0]
"你" → [0, 0, 1, 0, 0, 0]
```

问题：每个词都是正交的，"爱"和"恨"的距离 = "爱"和"猫"的距离。没有语义信息。

**词嵌入（Word Embedding）** 用一个**更短的稠密向量**来表示每个词：

```
"我" → [0.21, -0.53, 0.87, 0.12]    ← 4 维向量
"爱" → [0.83, 0.41, -0.22, 0.67]
"恨" → [-0.71, 0.38, -0.19, 0.72]   ← "恨"和"爱"的向量比较接近（都是情感动词）
"猫" → [0.02, 0.91, 0.55, -0.33]
```

这些数字从哪来？**学出来的。** 初始随机，训练过程中不断调整。

在 microgpt 中：

```python
# wte 是一个 (vocab_size, n_embd) 的矩阵
# 查表：wte[token_id] 就得到该 token 的 embedding 向量
tok_emb = state_dict['wte'][token_id]
```

比如 `vocab_size=27, n_embd=16`，那 `wte` 就是 27 行 16 列的矩阵，每行是一个 16 维向量。

### 2.2 位置编码（Positional Encoding）

Attention 有一个性质：**它不关心顺序。**

```
对 Attention 来说：
输入 ["我", "爱", "你"]
输入 ["你", "爱", "我"]

结果是一样的 — 它只看"谁和谁相关"，不看"谁在前面"。
```

这显然不行。所以必须**额外告诉模型每个词的位置**。

论文的方法：用三角函数为每个位置生成一个独特的编码向量：

```
PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
```

其中 `pos` 是位置编号（0, 1, 2, ...），`i` 是维度编号，`d_model` 是嵌入维度。

举个具体例子，假设 `d_model = 4`：

```
位置 0: [sin(0/1),    cos(0/1),    sin(0/100),    cos(0/100)]
       = [0,          1,           0,             1           ]

位置 1: [sin(1/1),    cos(1/1),    sin(1/100),    cos(1/100)]
       = [0.841,      0.540,       0.010,         0.999       ]

位置 2: [sin(2/1),    cos(2/1),    sin(2/100),    cos(2/100)]
       = [0.909,      -0.416,      0.020,         0.999       ]

位置 3: [sin(3/1),    cos(3/1),    sin(3/100),    cos(3/100)]
       = [0.141,      -0.990,      0.030,         0.999       ]
```

每个位置的编码向量都**唯一且不同**，低维度变化快（区分相邻位置），高维度变化慢（区分远距离位置）。

最后：

```
x = token_embedding + positional_embedding
```

逐元素相加，融合了"是什么词"和"在哪个位置"两种信息。

microgpt 用的是**可学习的位置编码**（`wpe` 矩阵），不用三角函数，而是直接学：

```python
pos_emb = state_dict['wpe'][pos_id]  # 查表，和 token embedding 一样
x = [t + p for t, p in zip(tok_emb, pos_emb)]
```

## 三、核心：Self-Attention 机制详解

这是论文标题里的 "Attention"，是整个 Transformer 的灵魂。我们用一个完整的手算例子走一遍。

### 3.1 设定

假设输入是 3 个词，每个词已经被 embedding 成 4 维向量：

```
x₁ = [1.0, 0.5, -0.3, 0.8]   ← "我"
x₂ = [0.2, 1.1,  0.7, -0.4]  ← "爱"
x₃ = [-0.5, 0.3, 1.2, 0.6]   ← "你"
```

### 3.2 生成 Q、K、V

每个词的 x 通过三个不同的线性变换，变成 Q、K、V：

```
Q = x × W_Q
K = x × W_K
V = x × W_V
```

W_Q、W_K、W_V 是三个**可学习的矩阵**，形状都是 `(d_model, d_k)`。

假设 `d_k = 3`（为了手算方便），随机初始化的权重矩阵：

```
W_Q = [[0.1, 0.3, 0.2],
       [0.4, 0.1, 0.5],
       [0.2, 0.6, 0.3],
       [0.3, 0.2, 0.4]]

W_K = [[0.5, 0.2, 0.1],
       [0.3, 0.4, 0.6],
       [0.1, 0.3, 0.2],
       [0.4, 0.1, 0.5]]

W_V = [[0.2, 0.4, 0.1],
       [0.5, 0.1, 0.3],
       [0.3, 0.5, 0.2],
       [0.1, 0.3, 0.4]]
```

### 3.3 手算 Q₁（"我"的 Query 向量）

```
Q₁ = x₁ × W_Q
    = [1.0, 0.5, -0.3, 0.8] × W_Q

第 1 个分量:
  1.0×0.1 + 0.5×0.4 + (-0.3)×0.2 + 0.8×0.3
= 0.1  +  0.2  +  (-0.06) +  0.24
= 0.48

第 2 个分量:
  1.0×0.3 + 0.5×0.1 + (-0.3)×0.6 + 0.8×0.2
= 0.3  +  0.05 +  (-0.18) +  0.16
= 0.33

第 3 个分量:
  1.0×0.2 + 0.5×0.5 + (-0.3)×0.3 + 0.8×0.4
= 0.2  +  0.25 +  (-0.09) +  0.32
= 0.68
```

所以 `Q₁ = [0.48, 0.33, 0.68]`

**直觉：** Q₁ 是"我"发出的**查询**，描述了"我"正在寻找什么样的信息。

### 3.4 类似地算出所有 Q、K、V

```
Q₁ = [0.48, 0.33, 0.68]     K₁ = [0.71, 0.56, 0.33]     V₁ = [0.44, 0.79, 0.29]
Q₂ = [0.30, 0.75, 0.42]     K₂ = [0.47, 0.75, 0.62]     V₂ = [0.78, 0.38, 0.26]
Q₃ = [0.28, 0.55, 0.35]     K₃ = [0.10, 0.45, 0.31]     V₃ = [0.28, 0.48, 0.41]
```

### 3.5 计算注意力分数：QK^T

每个词的 Q 和所有词的 K 做点积，得到"匹配分数"：

```
以"我"（Q₁）为例，计算它对每个位置的注意力分数：

score(我→我) = Q₁ · K₁ = 0.48×0.71 + 0.33×0.56 + 0.68×0.33
             = 0.341 + 0.185 + 0.224
             = 0.750

score(我→爱) = Q₁ · K₂ = 0.48×0.47 + 0.33×0.75 + 0.68×0.62
             = 0.226 + 0.248 + 0.422
             = 0.896

score(我→你) = Q₁ · K₃ = 0.48×0.10 + 0.33×0.45 + 0.68×0.31
             = 0.048 + 0.149 + 0.211
             = 0.408
```

所有分数组成矩阵（完整算完）：

```
            K₁(我)   K₂(爱)   K₃(你)
Q₁(我)   [  0.750,   0.896,   0.408 ]
Q₂(爱)   [  0.550,   0.775,   0.325 ]
Q₃(你)   [  0.420,   0.612,   0.265 ]
```

**这个矩阵就是 QK^T。每个元素代表：行对应的词对列对应的词的"关注度原始分数"。**

### 3.6 缩放（Scale）：除以 √d_k

```
scores = QK^T / √d_k = QK^T / √3 ≈ QK^T / 1.732

            K₁       K₂       K₃
Q₁(我)   [ 0.433,   0.517,   0.235 ]
Q₂(爱)   [ 0.318,   0.447,   0.188 ]
Q₃(你)   [ 0.242,   0.353,   0.153 ]
```

**为什么要缩放？**

当 d_k 很大时（比如 64），点积的值会很大（多个大数相加）。 softmax 在输入很大时梯度趋近于 0（进入"饱和区"），导致训练几乎无法进行。除以 √d_k 把值拉回到正常范围。

```
没有缩放时：softmax([10, 8, 3]) ≈ [0.87, 0.12, 0.001]  ← 极度不均匀
缩放后：    softmax([1.25, 1.0, 0.375]) ≈ [0.38, 0.30, 0.32]  ← 更均匀
```

### 3.7 Softmax：变成概率

对每一行做 softmax：

```
softmax([0.433, 0.517, 0.235])

步骤：
1. 减最大值（数值稳定）: [0.433-0.517, 0.517-0.517, 0.235-0.517] = [-0.084, 0, -0.282]
2. 取 exp:              [e^(-0.084), e^0, e^(-0.282)] = [0.919, 1.000, 0.754]
3. 求和:                0.919 + 1.000 + 0.754 = 2.673
4. 归一化:              [0.919/2.673, 1.000/2.673, 0.754/2.673]
                       = [0.344, 0.374, 0.282]
```

完整注意力权重矩阵：

```
            我       爱       你
我       [ 0.344,   0.374,   0.282 ]
爱       [ 0.302,   0.423,   0.275 ]
你       [ 0.318,   0.389,   0.293 ]
```

**解读：**
- "我"把 37.4% 的注意力放在"爱"上，34.4% 放在自己身上，28.2% 放在"你"上
- 每行之和 = 1（概率分布）

### 3.8 加权求和：注意力 × V

```
output_我 = 0.344 × V₁ + 0.374 × V₂ + 0.282 × V₃

第 1 维:
  0.344×0.44 + 0.374×0.78 + 0.282×0.28
= 0.151 + 0.292 + 0.079
= 0.522

第 2 维:
  0.344×0.79 + 0.374×0.38 + 0.282×0.48
= 0.272 + 0.142 + 0.135
= 0.549

第 3 维:
  0.344×0.29 + 0.374×0.26 + 0.282×0.41
= 0.100 + 0.097 + 0.116
= 0.313
```

所以 `output_我 = [0.522, 0.549, 0.313]`

**这就是"我"经过 Self-Attention 后的新表示。** 它不再是孤立的"我"，而是融合了上下文（"爱"和"你"）的信息。

### 3.9 总结 Attention 的完整公式

```
Attention(Q, K, V) = softmax(QK^T / √d_k) × V
                      ├─┘  ├──┘  ├─┘         ├─┘
                      概率   匹配  缩放        取内容
```

在 microgpt 中的对应代码（第 124-132 行）：

```python
for h in range(n_head):
    hs = h * head_dim
    q_h = q[hs:hs+head_dim]                           # 当前位置的 Q
    k_h = [ki[hs:hs+head_dim] for ki in keys[li]]     # 所有历史位置的 K
    v_h = [vi[hs:hs+head_dim] for vi in values[li]]   # 所有历史位置的 V

    # QK^T / √d_k
    attn_logits = [sum(q_h[j] * k_h[t][j] for j in range(head_dim))
                   / head_dim**0.5 for t in range(len(k_h))]
    # softmax
    attn_weights = softmax(attn_logits)
    # × V
    head_out = [sum(attn_weights[t] * v_h[t][j] for t in range(len(v_h)))
                for j in range(head_dim)]
```

## 四、Multi-Head Attention（多头注意力）

### 4.1 为什么需要多头？

单头注意力只有一个 Q/K/V 变换，只能学到**一种**关联模式。

但语言中的关联是多种多样的：

```
"猫坐在垫子上，它很满意"

关联1（指代）: "它" → "猫"        （语义关联）
关联2（语法）: "坐" → "在"        （语法结构）
关联3（位置）: "垫子" → "上"      （空间关系）
```

多头注意力让模型**同时学习多种关联模式**。

### 4.2 怎么做多头？

不是简单重复计算。做法是把 embedding 维度**切成多段**，每段交给一个头：

```
假设 n_embd = 8, n_head = 4, 则 head_dim = 8/4 = 2

原始 Q = [q0, q1, q2, q3, q4, q5, q6, q7]  (8 维)

切分：
  Head 0: Q₀ = [q0, q1]     ← 2 维
  Head 1: Q₁ = [q2, q3]
  Head 2: Q₂ = [q4, q5]
  Head 3: Q₃ = [q6, q7]
```

每个头**独立**做上面讲的 Attention 计算，得到各自的输出：

```
Head 0: output₀ = [a0, a1]    (2 维)
Head 1: output₁ = [a2, a3]
Head 2: output₂ = [a4, a5]
Head 3: output₃ = [a6, a7]
```

拼接（Concat）：

```
concat = [a0, a1, a2, a3, a4, a5, a6, a7]   (回到 8 维)
```

再用一个线性变换 `W_O` 混合各头的结果：

```
output = concat × W_O     (8 维 → 8 维)
```

### 4.3 实际上论文中的做法

论文不是先算一个大 Q 再切分，而是**每个头有自己的 W_Q、W_K、W_V**：

```
d_model = 512, n_head = 8, d_k = d_v = 64

每个头有独立的: W_Q^i (512×64), W_K^i (512×64), W_V^i (512×64)

Head_i 的 Q = x × W_Q^i   → 64 维
Head_i 的 K = x × W_K^i   → 64 维
Head_i 的 V = x × W_V^i   → 64 维

8 个头各自算 Attention → 8 个 64 维输出
Concat → 512 维
× W_O (512×512) → 512 维最终输出
```

**数学上等价于**一个大矩阵分成了 8 个小块，只是实现方式不同。microgpt 用的就是切分方式：

```python
for h in range(n_head):
    hs = h * head_dim
    q_h = q[hs:hs+head_dim]           # 取出属于第 h 个头的那一段
    ...
    x_attn.extend(head_out)            # 把各头输出拼回来
x = linear(x_attn, state_dict[f'layer{li}.attn_wo'])  # 最后的 W_O 变换
```

## 五、Feed-Forward Network（前馈网络）

### 5.1 结构

每个 Transformer 层除了 Attention，还有一个 MLP：

```
FFN(x) = W₂ × ReLU(W₁ × x + b₁) + b₂
```

两层线性变换，中间夹一个 ReLU 激活函数。

```
输入: x (512 维)
  ↓
W₁ (512 × 2048)  →  2048 维（扩展 4 倍）
  ↓
ReLU(max(0, x))  →  引入非线性
  ↓
W₂ (2048 × 512)  →  512 维（缩回来）
  ↓
输出: (512 维)
```

### 5.2 为什么要扩展再缩回？

**扩展 4 倍**给了网络更大的"工作空间"。在 2048 维的高维空间里，不同特征更容易被分离。ReLU 丢弃负值（给 0），这是一种最简单的非线性，让网络能学到复杂的模式。

### 5.3 关键性质：逐位置独立

Attention 是**跨位置**的（不同位置的词相互交互），而 FFN 是**逐位置**的：

```
Attention 之后，每个位置的向量已经融合了上下文信息。
FFN 对每个位置的向量独立做同样的变换（同样的 W₁、W₂）。

就像：
  Attention = 开会讨论（大家交流信息）
  FFN       = 各自回去消化（每个人独立思考）
```

## 六、残差连接（Residual Connection）和 LayerNorm

### 6.1 残差连接

每个子层（Attention 或 FFN）的输出不是直接替代输入，而是**加回输入**：

```
output = x + Sublayer(x)
```

```
不用残差:                    用残差:
  x → Sublayer → output       x ──→ (+) → output
                                   ↑    |
                              Sublayer(x)
```

**为什么有效？** 直觉理解：

```
没有残差时，梯度要从 loss 一层层传回来：
  loss → Layer6 → Layer5 → Layer4 → ... → Layer1
  每经过一层，梯度可能缩小一点（梯度消失）

有残差时，梯度可以直接"跳过去"：
  loss → Layer6 ──→ Layer4 ──→ Layer2 ──→ ...
             跳过5    跳过3    跳过1
  梯度有了一条"高速公路"
```

这在 microgpt 中就是：

```python
x_residual = x
x = linear(x_attn, state_dict[f'layer{li}.attn_wo'])
x = [a + b for a, b in zip(x, x_residual)]   # 加回原始输入
```

### 6.2 Layer Normalization

对向量做归一化，使其均值为 0，方差为 1：

```
输入: x = [2.1, -0.5, 1.3, 0.8]

1. 算均值: μ = (2.1 + (-0.5) + 1.3 + 0.8) / 4 = 0.925
2. 算方差: σ² = ((2.1-0.925)² + (-0.5-0.925)² + (1.3-0.925)² + (0.8-0.925)²) / 4
           = (1.381 + 2.031 + 0.141 + 0.016) / 4 = 0.892
3. 归一化: x_hat = [(2.1-0.925)/√0.892, (-0.5-0.925)/√0.892, (1.3-0.925)/√0.892, (0.8-0.925)/√0.892]
           = [1.245, -1.508, 0.397, -0.132]
4. 缩放:  output = γ * x_hat + β   (γ、β 是可学习参数)
```

microgpt 用的是 **RMSNorm**（简化版，不减均值，只除均方根）：

```python
def rmsnorm(x):
    ms = sum(xi * xi for xi in x) / len(x)    # 均方
    scale = (ms + 1e-5) ** -0.5                # 1/√(均方)
    return [xi * scale for xi in x]
```

**为什么需要 Norm？** 训练过程中，数值可能越来越大或越来越小，Norm 把它们拉回正常范围，稳定训练。就像电路里的稳压器。

## 七、完整的 Transformer Block

论文中一个 Encoder 层的完整数据流：

```
输入 x
  │
  ├──→ LayerNorm(x) ──→ Multi-Head Attention ──→ (+) ──→ x₁
  │                                              ↑
  └──────────────────────────────────────────────┘  (残差)

  x₁
  │
  ├──→ LayerNorm(x₁) ──→ FFN ──→ (+) ──→ x₂
  │                          ↑
  └──────────────────────────┘  (残差)

输出 x₂
```

microgpt 的对应代码（第 114-141 行）：

```python
for li in range(n_layer):
    # ---- Attention Block ----
    x_residual = x
    x = rmsnorm(x)                                         # Pre-Norm
    q = linear(x, state_dict[f'layer{li}.attn_wq'])       # 算 Q
    k = linear(x, state_dict[f'layer{li}.attn_wk'])       # 算 K
    v = linear(x, state_dict[f'layer{li}.attn_wv'])       # 算 V
    ...                                                     # Multi-Head Attention
    x = linear(x_attn, state_dict[f'layer{li}.attn_wo'])  # 输出投影
    x = [a + b for a, b in zip(x, x_residual)]             # 残差连接

    # ---- FFN Block ----
    x_residual = x
    x = rmsnorm(x)                                         # Pre-Norm
    x = linear(x, state_dict[f'layer{li}.mlp_fc1'])        # 扩展 4 倍
    x = [xi.relu() for xi in x]                            # ReLU
    x = linear(x, state_dict[f'layer{li}.mlp_fc2'])        # 缩回来
    x = [a + b for a, b in zip(x, x_residual)]             # 残差连接
```

注意论文用的是 **Post-Norm**（先 Sublayer 后 Norm），microgpt 用 **Pre-Norm**（先 Norm 后 Sublayer），这是 GPT 系列的改进，训练更稳定。

## 八、Decoder 的特殊之处

### 8.1 Masked Self-Attention

Decoder 在生成时**不能看到未来的词**（否则就作弊了）。方法是给未来位置的注意力分数设为 `-∞`：

```
假设正在处理位置 1（"爱"），当前已生成 [我, 爱]

未遮掩的注意力分数:         遮掩后的注意力分数:
       我    爱    你              我    爱    你
我  [ 0.75, 0.90, 0.41 ]    我  [ 0.75, 0.90, 0.41 ]   ← 位置 0 能看到所有
爱  [ 0.55, 0.78, 0.33 ]    爱  [ 0.55, 0.78, -∞   ]   ← 位置 1 不能看到"你"
你  [ 0.42, 0.61, 0.27 ]    你  [  -∞ ,  -∞ ,  -∞  ]   ← 位置 2 全部遮住

softmax 后:
       我      爱      你
爱  [ 0.44,  0.56,   0.00 ]   ← "你"的概率变成 0，完全看不到
```

microgpt 没有显式的 mask，因为它**逐 token 生成**，每次只输入当前 token，keys/values 通过列表缓存自然实现了因果性（只会看到之前的位置）。

### 8.2 Cross-Attention（交叉注意力）

这是原版 Transformer Decoder 独有的，microgpt（GPT 架构）**没有**这一层：

```
Decoder 的 Attention 有两种：
1. Self-Attention:  Q/K/V 都来自 Decoder 自己（已生成的词）
2. Cross-Attention: Q 来自 Decoder，K/V 来自 Encoder 的输出

Cross-Attention 让 Decoder 在生成每个词时，
都能"回头看"源语言（比如英语）的所有信息。

比如生成"爱"时，Cross-Attention 可能高度关注 Encoder 中"love"的表示。
```

GPT 只做文本生成，不需要翻译源语言，所以去掉了 Cross-Attention 和整个 Encoder。

## 十、训练目标

整个模型训练的目标只有一个：**让正确的下一个词概率最大**。

```
训练数据: "I love you" → "我爱你"

Decoder 输入:  <BOS>   我     爱
目标输出:       我      爱    你

对每个位置算交叉熵损失:
loss = -log(P(我|<BOS>)) - log(P(爱|<BOS>我)) - log(P(你|<BOS>我爱))
```

然后反向传播算梯度，Adam 更新参数，反复迭代。

## 十三、为什么 Transformer 革命性地改变了 AI？

| RNN（旧方法） | Transformer（新方法） |
|---|---|
| 从左到右逐步处理，慢 | 所有位置**同时**计算，可并行 |
| 距离远的词难关联 | 任何两个词之间**一步直达** |
| 难以训练很深 | 残差连接让深层训练成为可能 |

正是这个架构，才让后来的 GPT-2/3/4、BERT、ChatGPT 成为可能。
