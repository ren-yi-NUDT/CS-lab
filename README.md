# 计算机系统实验 11 —— 多线程搜索密码

把 `SearchRandom.c` 单线程穷举改写为多线程 + AVX2 SIMD + 内嵌汇编的并行版本。

## 文件

| 文件 | 说明 |
|------|------|
| `SearchRandom.c` | 基线单线程版（原版） |
| `Thread.c` | 实验组（多线程 + AVX2 + 内嵌汇编） |
| `Makefile` | 一键编译 |
| `run.sh` | 一键运行基线和实验组 |
| `helpme.md` | **详细设计文档**（多线程 / SIMD / 内嵌汇编思路） |
| `requirements.txt` | pptx 实验要求 |
| `计算机系统-实验11.pptx` | 实验讲义 |

## 编译

```bash
make
```

生成两个可执行文件：`SearchRandom`（基线）、`Thread`（实验组）。

## 运行

### 一键对比（推荐）

```bash
./run.sh            # 基线 + 实验组（默认 8 线程）
./run.sh 24         # 基线 + 实验组 24 线程
./run.sh sweep      # 基线 + 实验组多线程数扫描（4/8/16/24/32/64）
```

### 手动运行

```bash
./SearchRandom                  # 基线单线程
./Thread           # 默认 8 线程
./Thread 24        # 指定 24 线程
```

## 性能（i9-14900HX, 24 逻辑核）

| 版本 | 最快耗时 | 加速比 |
|------|---------|--------|
| 基线单线程 | ~13 s | 1× |
| 实验组（64 线程） | **0.086 s** | **~151×** |

实验组找到的密码与基线一致（`70FFFFFF`、`857CDC19`、`FB3E6E0C`）。
